Personal cybersecurity home lab

I plan to build an isolated virtual lab to practice networking, system administration, and security monitoring. The goal is to connect concepts from my UC coursework with repeatable, hands-on exercises.

The plan

Set up Windows and Linux virtual machines, configure a small test network, and capture traffic with Wireshark. Practice account permissions, updates, and basic system hardening.

What I want to learn

How normal network activity looks, how configuration choices affect security, and how to document findings clearly enough for someone else to follow.

Evidence to add

A network diagram, sanitized screenshots, setup notes, and a reflection explaining what worked, what failed, and what I would improve.
